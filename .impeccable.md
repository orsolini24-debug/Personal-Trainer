# Impeccable Design Context — Performance Ecosystem

## Design Context

### Users
Athletes training 3–5+ sessions/week. Performance-first mindset: they track data obsessively, want fast access to metrics, and expect the app to respect their discipline. Future use includes other serious athletes — not casual gym-goers. Use contexts: pre/post workout on mobile, deeper analysis on desktop.

### Brand Personality
**Three words**: Precision. Power. Progress.
**Voice**: Direct, technical, motivating — like a high-performance coach, not a wellness influencer.
**Emotional goal**: The app should feel like putting on training gear — focused, ready, purposeful.

### Aesthetic Direction
The app has two distinct emotional modes that must feel intentional, not just a color swap:

**Dark mode → Military Discipline**
- Reference: Suunto app — precise data visualization, dark tactical surfaces, no decorative noise
- Feel: Mission control. Every element earns its place. No ornamentation.
- Palette direction: Deep gunmetal/midnight backgrounds, sharp electric-blue or amber accent (targeting reticle energy), high contrast data readout
- Typography: Heavy weights for data, mechanical precision

**Light mode → Athletic Energy**
- Reference: Nike Training Club — kinetic, bold, driven
- Feel: Stadium lights on. Ready to push. High contrast, warm vitality.
- Palette direction: Clean white/light gray base, vivid accent (not pastel), strong type hierarchy
- Typography: Confident, impactful headlines, crisp body

### Anti-References
- Generic fitness apps (MyFitnessPal, generic health dashboards)
- Wellness/meditation aesthetics (soft, pastel, rounded)
- AI slop: cyan-on-dark, purple-to-blue gradients, glassmorphism everywhere, gradient text, hero metrics with big number + small label + gradient accent
- Tabular/spreadsheet layouts
- Rounded rectangles with a colored border on one side as decoration

### Design Principles
1. **Data first, decoration never** — Every visual element must serve data comprehension or user action. If it doesn't, remove it.
2. **Theme as emotion** — Dark and light are not just color inversions; they are distinct emotional states. Dark = focus/discipline, Light = energy/movement.
3. **Hierarchy through weight, not gimmicks** — Size contrast, weight contrast, and whitespace create hierarchy. Not gradients, glows, or borders.
4. **Motion with purpose** — State transitions get animation. Decoration does not.
5. **Athletic typography** — Headlines command attention. Body text is efficient. Numbers are always tabular and crisp.

### Typography
- **Display/Headings**: Sora 800–900 (retained — geometric, athletic, distinctive. NOT Inter)
- **Body**: Outfit 400–600 (replaces Inter — geometric, athletic energy, excellent number rendering)
- **Data/Mono**: JetBrains Mono (metrics, timestamps, code)
- **Scale**: Dramatic size jumps (5xl+ for key metrics, not uniform 1.25x steps)

### Color Philosophy
- Avoid: purple-to-blue gradient as decorative accent (AI slop fingerprint)
- Avoid: gradient text on headings/logos
- Avoid: pure #000/#fff — always tinted
- Tinted neutrals: dark backgrounds should hint toward the accent hue
- One bold accent, one supporting semantic color system (positive/negative/warning)
- Light mode accent should feel energetic (warm) vs dark mode accent (cool precision)
